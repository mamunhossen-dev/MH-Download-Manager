# MH Download Manager 🇧🇩

### A Powerful Windows Download Manager

**Fast • Smart • Reliable**

MH Download Manager is a feature-rich Windows download manager built with C# and .NET 8. Powered by aria2 and yt-dlp, it supports multi-connection downloads, video and playlist downloading, BitTorrent, Gofile, and browser integration.

## ✨ Features

- **Fast Downloads:** Multi-connection downloading powered by aria2, supporting up to 16 connections.
- **Video & Playlist Downloader:** Download videos, playlists and channels with quality selection and MP3 audio extraction.
- **BitTorrent Support:** Download `.torrent` files and magnet links.
- **Browser Integration:** Capture downloads from Chrome, Microsoft Edge, Brave and Firefox.
- **Gofile Downloader:** Download files and folders from Gofile links.
- **Download Management:** Pause, resume, remove and monitor downloads.
- **Download Queue:** Manage multiple video downloads with configurable parallel processing.
- **Automatic Shutdown:** Shut down your PC after downloads finish.
- **Smart Dependency Setup:** Helps install required components such as aria2, yt-dlp, FFmpeg and Deno.
- **Windows Installer:** Easy installation with Start Menu and Desktop shortcuts.
